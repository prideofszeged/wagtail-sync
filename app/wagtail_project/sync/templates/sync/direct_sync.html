How the File-Based Sync Works

This sync method uses a file-based approach to transfer content between instances:

  1. On the source instance, click "Export Content" to export content to a JSON file
  2. On the target instance, click "Import Content" to import the content from the JSON file

The JSON file is stored in the shared volume between containers, so you don't need to manually transfer files.

Command Line Alternative

You can also use the management command to export/import content:

python manage.py direct_sync

To import content:

python manage.py direct_sync --import
