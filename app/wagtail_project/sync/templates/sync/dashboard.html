Command Line Sync

You can also use the management command to sync content between instances:

python manage.py direct_sync

This command will export content to a file that can be imported on the other instance.

To import content:

python manage.py direct_sync --import

Options:

  • --page-ids: Specify specific page IDs to sync
  • --export-file: Specify a custom export file name
